nekonomarch pipeline

nekonomarch pipeline は、YouTube チャンネル「ねこのマーチ March the Cat」（@nekonomarch）の運営者が、自身のチャンネルへの動画の予約投稿と分析データの取得を自動化するために使う個人用のコマンドラインツールです。一般には配布していません。

What it does / できること

  • 運営者が撮影した猫の動画を、運営者の Mac 上で編集する（YouTube API は使わない）
  • 完成した動画を運営者自身のチャンネルへ予約投稿する（YouTube Data API: videos.insert、thumbnails.set、playlists、playlistItems）
  • 運営者自身のチャンネルの視聴データを取得して、週次のまとめを作る（YouTube Analytics API、読み取りのみ）

This tool uses YouTube API Services. It accesses only the channel owner's own account and data, and has no other users.
