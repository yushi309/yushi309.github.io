nekonomarch pipeline プライバシーポリシー

nekonomarch pipeline は、YouTube チャンネル「ねこのマーチ March the Cat」（@nekonomarch）の運営者が、自身のチャンネルへの動画投稿と分析データの取得を自動化するために使用する個人用ツールです。

  • 利用するのは運営者本人の Google アカウントのみで、第三者のデータは取得・保存しません。
  • YouTube Data API と YouTube Analytics API を通じて取得した情報（動画のメタデータ、再生数などの統計）は、運営者の個人所有のコンピュータにのみ保存し、外部に提供・販売しません。
  • 認証トークンは運営者のコンピュータ内に保存し、第三者と共有しません。
  • 本ツールは Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

Privacy Policy

nekonomarch pipeline is a personal tool used by the owner of the YouTube channel "March the Cat" (@nekonomarch) to automate uploads to, and analytics retrieval from, the owner's own channel.

  • It accesses only the owner's own Google account and does not collect or store any third-party data.
  • Data obtained via the YouTube Data API and YouTube Analytics API (video metadata, view statistics) is stored only on the owner's personal computer and is never shared or sold.
  • Authentication tokens are stored locally on the owner's computer and are not shared with anyone.
  • This tool complies with the Google API Services User Data Policy, including the Limited Use requirements.
