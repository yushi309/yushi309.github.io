nekonomarch pipeline プライバシーポリシー

最終更新: 2026-09-13

nekonomarch pipeline（以下「本ツール」）は、YouTube チャンネル「ねこのマーチ March the Cat」（@nekonomarch）の運営者が、自身のチャンネルへの動画投稿と分析データの取得を自動化するために使用する個人用ツールです。

YouTube API Services の利用

  • 本ツールは YouTube API Services を利用します。利用にあたっては YouTube の利用規約 と Google のプライバシーポリシー が適用されます。
  • 利用するのは運営者本人の Google アカウントのみで、第三者（他のユーザー、他のチャンネル、視聴者）のデータは取得・保存しません。

取得するデータと用途

  • 運営者自身のチャンネルの動画情報（動画 ID、タイトル、公開日時）と、YouTube Analytics API から取得する運営者自身のチャンネルの統計（再生数、総再生時間など）。
  • 用途は、運営者自身の動画の予約投稿の記録と、運営者が読む週次のまとめの作成に限ります。

保存と共有

  • 取得したデータは運営者の個人所有のコンピュータ内にのみ保存し、外部のサーバーには送信しません。第三者に提供・販売・共有しません。
  • 認証トークンは運営者のコンピュータ内に保存し、第三者と共有しません。
  • Cookie は使用しません。

データの削除とアクセスの取り消し

  • 保存したデータは、運営者がローカルのデータベースファイルを削除することでいつでも消去できます。
  • 本ツールへの Google アカウントのアクセス許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。取り消し後、本ツールは API にアクセスできなくなります。

Privacy Policy

Last updated: 2026-09-13

nekonomarch pipeline ("the Tool") is a personal tool used by the owner of the YouTube channel "March the Cat" (@nekonomarch) to automate uploads to, and analytics retrieval from, the owner's own channel.

Use of YouTube API Services

  • The Tool uses YouTube API Services. Its use is subject to the YouTube Terms of Service and the Google Privacy Policy.
  • The Tool accesses only the owner's own Google account. It does not collect or store any data about other users, other channels, or viewers.

Data collected and how it is used

  • Metadata of the owner's own videos (video ID, title, publish time) and the owner's own channel statistics from the YouTube Analytics API (views, watch time, etc.).
  • This data is used only to keep a record of the owner's scheduled uploads and to produce a weekly summary read by the owner.

Storage and sharing

  • All data is stored only on the owner's personal computer and is never sent to external servers, shared, sold, or disclosed to any third party.
  • Authorization tokens are stored locally on the owner's computer and are not shared with anyone.
  • The Tool does not use cookies.

Data deletion and revoking access

  • Stored data can be deleted at any time by deleting the local database file.
  • The owner can revoke the Tool's access to their Google account at any time via the Google security settings page. After revocation the Tool can no longer access the APIs.
